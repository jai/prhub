# PRKit

> PRHub's PR screens as a Swift package: PRHub (`app/`) is one host, and any app can embed them as one tab.

PRKit holds the PR screens, their models, the pr-worker client and the design parts the rest of the app draws with.
An app gives it a host (`PRKitHost`) and shows `PRKitRoot` in a tab. Nothing else of the app is inside.

## Products

| Product | What it holds | Imports |
|---|---|---|
| `PRKitCore` | `PullRequestRef` and `PRLinkParser` (a github.com PR link or `owner/repo#N`), the rows and list models, `PRViewerClient`, `PRWrite`, the Ask AI models | Foundation, and the package-only `PRKitNetwork` (the transport and `withDeadline`). Safe in an app extension. |
| `PRKitDesign` | DESIGN.md's tokens (`DesignTokens`, `Space`, `Radius`, `MotionTokens`, generated by `make -C app design` from the root `DESIGN.md`), the colour roles (`AppColor.swift`: `Color.toneGood`, `.groundCard`…), the parts' measures (`Metrics.swift`: `PRStyle`, `ChatStyle`, `ChipStyle`, `MarkdownStyle`), `AppFont`, `HomePalette`, `AppIcon`, `AppMotion` | SwiftUI. A widget can link this alone. |
| `PRKit` | The screens, `PRsModel`, `PRSession`, the mirror, the shared list and chat parts, and the host API | Both of the above, re-exported. |

## Embed it

1. Add the package: `.package(url: "https://github.com/jai/prhub", from: "0.1.0")`, product `PRKit` (in XcodeGen:
   `packages: PRKit: {url: https://github.com/jai/prhub, from: 0.1.0}`). PRHub uses the local path (`app/project.yml`).
2. Write a host: a `@MainActor` class that conforms to `PRKitHost`.
3. Make one `PRKitController(host:)` at launch and keep it. A silent push syncs PRs with no scene on screen.
4. Show `PRKitRoot(controller)` in a tab, and put `.prKitEnvironment(controller)` on the root, so a PR link on any tab
   opens the PR there.
5. Put `DiffFontSection()` in the app's Settings `Form`: the diff's font and size, which every diff follows. Its fonts
   ship in the package and register themselves; the app's Info.plist needs nothing.

```swift
let prs = PRKitController(host: PRHubPRHost(access: .paired(endpoint: endpoint, secret: secret), samples: nil))

Tab("PRs", systemImage: "arrow.triangle.pull", value: PRHubTab.prs) {
    PRKitRoot(prs)
}
```

PRHub's host is `app/PRHub/App/PRHubHost.swift`.

## What the host gives

| `PRKitHost` member | What it is |
|---|---|
| `access` | The Worker's base URL and the bearer for each request (`PRViewerAccess`). Read once. |
| `isInForeground()` | Whether the app is in front: a request then waits for a network. |
| `configuration` | The features the Worker serves (`askAI`, `keyLines`, `rewrite`, `push`), the org filter's default and the GitHub login. Read each time a screen asks. |
| `outbox` | A queue that keeps a write until the Worker has it (`PRKitOutbox`), or `nil` to send writes straight to the Worker. The host hands each answer back through `outboxAnswered` and `outboxRefused`. |
| `apnsEnvironment` | `production` or `sandbox`, for `POST /device/register`. |
| `samples` | Made-up PRs with no Worker (`PRSampleSet`), or `nil`. |
| `launchOptions` | A UI test's or benchmark's request to open a PR; `.none` otherwise. |
| `receive(_:)` | Every `PRKitEvent`. |
| `log(_:)` | A PR's files that failed to download or be written, for the host's event log. |

The host also ships the named colours and the GitHub PR images in its asset catalogue (`ToneGood`, `ToneBad`,
`ToneWaiting`, `ToneMerged`, `GitHubPROpen`, `GitHubPRDraft`, `GitHubPRMerged`, `GitHubPRClosed`, `LinearMark`): the
package reads them from the main bundle. PRHub's are in `app/PRHub/Assets.xcassets`.

## Messages in and out

- In, on `PRKitController`: `refresh(_:)` for a wake or a foreground, `register(apnsToken:)`, `open(_:)` for a
  `PullRequestRef`, `open(text:)` for words that may name a PR, `popToRoot()`, `forgetEverything()`, and the outbox's
  answers. The host selects its own PRs tab.
- Out, to `PRKitHost.receive`: `.opened(ref)`, `.synced(trigger, outcome)`, `.reviewRequests(count)` for a badge,
  `.writeRefused(words)`.

## How the PRs stay on the phone

`PRMirror` is an actor and owns every file of the mirror. A pull waits for the list only; each PR's description and
diff download behind it, one download per file and six at a time across every sync. Each list fetch has a generation,
and only the newest one's rows are published. Prune keeps what the newest list and the shown rows name and anything
still downloading. A PR shows a revision only when both of its files are on disk; one that fails for good keeps its last
good revision until a pull.

## Tests

`swift test` at the repo root runs `PRKitTests` on macOS; `make -C app test` runs them again on an iOS Simulator with the
app's own tests. `FixtureContractTests` and `PRPushTests` decode the Worker's golden fixtures in `docs/fixtures/`.
